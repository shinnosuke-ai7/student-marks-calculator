# Student Marks Calculator
# Project Description
This is a beginner-friendly Python project developed to calculate a student’s total marks, average marks, and grade based on marks entered by the user.  
The program also checks for invalid marks entered by the user.

# Features
- Takes student name as input
- Accepts marks for 3 subjects
- Calculates total marks
- Calculates average marks
- Displays grade based on average
- Validates invalid marks
- Uses conditional statements and formatted output

# Technologies Used
- Python
- Conditional Statements
- User Input Handling
- Basic Validation
- Formatted Strings (f-strings)

# Sample Output

Enter student name: Devansh
Enter marks1: 85
Enter marks2: 90
Enter marks3: 80

Student Name: Devansh
Total Marks: 255
Average Marks: 85.00
Grade: B
